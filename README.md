# Registro de Empleados

Programa de consola en C# para registrar y consultar empleados.

## Funciones
- Agregar empleados.
- Listar empleados y calcular nómina.
- Buscar empleados por nombre.
- Calcular factorial.

## Ejecución
Abrir el proyecto en Visual Studio Community 2026 y ejecutar con F5 o Ctrl + F5.
